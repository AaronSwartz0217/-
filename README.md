# 杭州求职避雷网

一个纯前端、单文件的公司求职黑名单查询页面。输入公司名称即可查询是否在黑名单中，命中后弹出避雷原因、风险标签及关联提醒。

数据来源于网络及个人求职经历整理，仅供参考，不构成任何法律或投资建议。

## 功能特性

- **模糊匹配查询**：输入公司名部分关键字即可命中，自动忽略「有限公司 / 科技 / 集团」等常见后缀和空格。
- **命中提示**：命中黑名单时弹出红色警示窗，展示公司名、避雷原因、风险标签。
- **关联提醒**：对同一实际控制人的关联企业（如创景路系）额外提示，避免换个马甲重复踩雷。
- **未命中提示**：未收录时弹出绿色提示，并提醒结合天眼查、脉脉等多方信息综合判断。
- **别名匹配**：同一公司的多个名称互为别名，任一名称均可查到。
- **纯前端零依赖**：单个 HTML 文件，无需服务器、无需构建，双击即用。

## 使用方法

直接用浏览器打开 [`index.html`](./index.html) 即可，无需任何依赖或服务器。

在搜索框输入公司名称，点击「查询」或按回车：

- 命中黑名单 → 弹出红色警示窗，显示避雷原因与风险标签。
- 未命中 → 弹出绿色提示窗，提示暂未收录。
- 多个匹配 → 列出候选，点击查看对应详情。

## 维护黑名单数据

所有数据集中在 [`index.html`](./index.html) 的 `BLACKLIST` 数组中，按如下格式追加一条即可：

```javascript
{
  name: "公司名称",
  reason: "避雷原因描述。",
  tags: ["标签1", "标签2"],
  alias: ["别名"],        // 可选：同一公司的其他名称
  group: "关联提醒说明。"  // 可选：同一实际控制人的关联企业提示
}
```

- `name`、`reason`、`tags` 为必填。
- `alias` 用于同一公司的多个名称互相匹配。
- `group` 用于提示关联企业，会在弹窗中以「关联提醒」区块单独展示。
