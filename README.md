# 杭州求职避雷网

一个纯前端的公司求职黑名单查询站点。输入公司名称即可查询是否在黑名单中，命中后弹出避雷原因、风险标签及关联提醒；也可切换到「按地区筛选」页面，按行政区或风险标签浏览避雷企业。

数据来源于网络及个人求职经历整理，仅供参考，不构成任何法律或投资建议。

## 功能特性

- **模糊匹配查询**：输入公司名部分关键字即可命中，自动忽略「有限公司 / 科技 / 集团」等常见后缀、括号备注和空格。
- **命中提示**：命中黑名单时弹出红色警示窗，展示公司简称、工商全名、所属行政区、避雷原因；风险标签直接融入避雷原因区块内一并展示。
- **关联提醒**：对同一实际控制人的关联企业（如创景路系）额外提示，避免换个马甲重复踩雷。
- **未命中提示**：未收录时弹出绿色提示，并提醒结合天眼查、脉脉等多方信息综合判断。
- **别名匹配**：同一公司的多个名称互为别名，任一名称均可查到。
- **按地区筛选**：独立的 [`regions.html`](./regions.html) 页面，点击杭州行政区地图上的区县即可筛选（单选），并可叠加风险标签组合筛选；卡片点击后弹出与搜索页完全一致的避雷详情弹窗。地图未收录企业的区县点击后提示「暂无收录企业」，杭州以外与全域企业以补充标签形式提供入口。
- **夜间模式**：右上角一键切换明暗主题，自动跟随系统偏好并记住手动选择，各页面共享主题。
- **小说模式**：左上角「避雷 / 小说」滑动开关切换，进入 [`novel.html`](./novel.html) 阅读求职者的真实经历与随笔——书架卡片列出作品，点击进入沉浸阅读，支持多章节翻页，风格与主站一致。
- **纯前端零依赖**：原生 HTML + CSS + JavaScript，无框架、无构建。

## 使用方法

由于页面通过外部 JS 文件加载数据，直接双击用 `file://` 打开可能因浏览器安全限制无法加载脚本，建议通过本地 HTTP 服务器打开：

```bash
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/index.html
```

在搜索框输入公司名称，点击「查询」或按回车：

- 命中黑名单 → 弹出红色警示窗，显示避雷原因与风险标签。
- 未命中 → 弹出绿色提示窗，提示暂未收录。
- 多个匹配 → 列出候选，点击查看对应详情。

点击左上角「地区筛选」进入 [`regions.html`](./regions.html)，选择行政区或风险标签即可查看对应避雷企业，点击卡片查看完整详情。

## 维护黑名单数据

所有数据集中在 [`data.js`](./data.js) 的 `BLACKLIST` 数组中，按如下格式追加一条即可：

```javascript
{
  name: "公司简称",              // 用于搜索匹配的常用名
  fullName: "工商规范全名",       // 弹窗与地区列表中展示的完整名称
  district: "余杭区",            // 所属行政区；杭州以外统一填「外地」，全域填「杭州全域」
  reason: "避雷原因描述。",
  tags: ["标签1", "标签2"],
  alias: ["别名"],              // 可选：同一公司的其他名称
  group: "关联提醒说明。"         // 可选：同一实际控制人的关联企业提示
}
```

- `name`、`fullName`、`district`、`reason`、`tags` 为必填。
- `district` 决定该公司在「按地区筛选」中归入哪个区块；杭州各区会出现在地图上，杭州以外统一归入「外地」区块，具体城市写在 `fullName` 和 `reason` 里即可。
- `alias` 用于同一公司的多个名称互相匹配。
- `group` 用于提示关联企业，会在弹窗中以「关联提醒」区块单独展示。
