# 杭州十年百万 · 求职卡牌策略游戏

在杭州工作 10 年（120 个月），累计净资产达到 **100 万元**即胜利；净资产跌破 **-5 万元**或 120 个月用完未达标即失败。

---

## 一、初始状态

| 项目 | 数值 |
|------|------|
| 初始净资产 | 15,000 元 |
| 起始月份 | 第 1 月 / 共 120 月 |
| 初始抽卡次数 | 随机 10 ~ 200 次 |
| 杭州地区加成 | 默认开启 |
| 胜利线 | 净资产 ≥ 1,000,000 元 |
| 破产线 | 净资产 < -50,000 元 |

## 二、卡牌系统

### 1. 等级与出现概率

每次抽卡按以下权重随机生成等级（归一化后为出现率）：

| 等级 | 名称 | 基础权重 | 杭州加成后权重 | 约出现率（加成后） |
|------|------|----------|----------------|--------------------|
| N | 错过 | 20 | 20 | ≈19.8% |
| R | 基层 | 40 | 40 | ≈39.6% |
| SR | 中级 | 30 | 35 | ≈34.7% |
| SSR | 高级 | 10 | 15 | ≈14.9% |
| SSSR | 作者 | 0.1 | 0.1 | ≈0.1%（千分之一） |

> 杭州加成开启时，SR 与 SSR 各 +5 权重；SSSR 概率极低（千分之一），仅可通过长期游玩或兑换码获取。

### 2. 工作名单与薪资

| 等级 | 月薪范围（元） | 工作示例 |
|------|----------------|----------|
| R | 2,000 ~ 6,000 | 外卖骑手、快递员、保安、保洁、餐厅服务员、工厂普工等（10 种） |
| SR | 6,000 ~ 10,000 | 程序员、设计师、运营专员、会计、销售经理等（10 种） |
| SSR | 10,000 ~ 20,000 | 产品总监、技术架构师、财务总监、运营总监等（8 种） |
| SSSR | 100,000（固定） | 作者（1 种） |

### 3. 录取率

抽到卡牌后可选择「录取」或「放弃」。录取成功率 = 等级基础录取率 × (地区录取率 / 100)。

| 等级 | 基础录取率 | 杭州加成后 |
|------|------------|------------|
| N | 0%（不可录取） | 0% |
| R | 80% | 85% |
| SR | 30% | 38% |
| SSR | 10% | 20% |
| SSSR | 100% | 100% |

> 录取失败（错失良机）不消耗当前工作，但该卡作废。

### 4. 黑心公司

- **出现概率**：20%（SSSR「作者」不会是黑心公司）
- **名单**：血汗工厂、皮包公司、996 科技、劳务中介陷阱、无良销售公司、克扣工资小作坊
- **隐藏机制**：抽卡时卡片不显示黑心标识，**录取入职后**才在「当前工作」卡片显示「黑心」标签
- **负面效果**：入职黑心公司后，意外事件中负面占比由 30% 升至 **60%**
- **薪资**：按原等级薪资正常发放，陷阱在于更高的坏事概率

## 四、月结算流程

每次「单抽 / 十连抽 / 跳过本月」都会先触发一次月结算，流程如下：

1. **收入**：randFloat(月薪下限, 月薪上限) × (1 - 过劳惩罚)；无业则收入为 0
2. **房租**：randFloat(地区月租下限, 地区月租上限)
3. **生活费**：地区固定生活费
4. **意外事件**：30% 概率触发（详见下节）
5. **净资产变化**：收入 - 房租 - 生活费 + 事件金钱
6. **离职判定**：按当前地区月离职率随机判定，触发则失去工作
7. **过劳惩罚**：本月应用后重置（下月重新累计）
8. **月份 +1**

> 无业时仍需支付房租和生活费，会持续亏损，应尽快抽卡入职。

## 五、事件系统

事件统一由「事件队列」管理：**先出抽卡结果弹窗，玩家处理完（录取/放弃）后，再依次弹出本月事件**。

### 1. 随机意外事件（30% 触发率）

触发后按以下占比判定正面/负面：

| 状态 | 正面占比 | 负面占比 |
|------|----------|----------|
| 正常 | 70% | 30% |
| 黑心公司 | 40% | 60% |

**正面事件（9 种）**

| 事件 | 效果 |
|------|------|
| 年终奖到账 | +3,000 ~ 8,000 元 |
| 项目奖金 | +2,000 ~ 5,000 元 |
| 贵人相助 | +3 次抽卡机会 |
| 副业收入 | +1,000 ~ 3,000 元 |
| 兼职接单 | +500 ~ 1,500 元 |
| 基金分红 | +2,000 ~ 6,000 元 |
| 退税到账 | +1,000 ~ 2,500 元 |
| 灵感迸发 | +2 次抽卡机会 |
| 亲友周转 | +3,000 ~ 5,000 元 |

**负面事件（11 种）**

| 事件 | 效果 |
|------|------|
| 公司拖欠工资 | 本月收入减半 |
| 招聘诈骗 | -2,000 元 |
| 无故辞退 | 立即失去当前工作 |
| 租房被骗 | -3,000 元 |
| 加班过劳 | 下月收入 -10%（可叠加） |
| HR 刁难 | 本月收入归零 |
| 突发医疗费 | -1,500 元 |
| 手机碎屏 | -2,500 元 |
| 团建自费 | -800 元 |
| 押金纠纷 | -1,200 元 |
| 迟到扣绩效 | 下月收入 -10% |

### 2. 抉择事件（15% 触发率）

在抽卡结果处理完后判定，触发时弹窗强制玩家二选一，直接影响当月。

| 场景 | 选项 A | 选项 B |
|------|--------|--------|
| 路遇扫码送礼 | 扫码领取（-800~+300 元，可能被盗刷） | 婉拒离开（+1 次抽卡） |
| 前同事拉创业 | 一起干（-3,000~+6,000 元，高风险） | 稳妥拒绝（清除过劳） |
| 项目紧急通宵 | 硬扛（+1,000~3,000 元，透支身体） | 准点下班（下月 -10%） |
| 房东要求涨租 | 接受（-500 元） | 据理力争（-1,500~+1,000 元） |
| 猎头高薪挖角 | 加微信（+3 次抽卡） | 不理会（清除过劳） |
| 地铁口老人求助 | 掏 20 元（-20 元） | 走开（下月 -5%） |
| 体检指标异常 | 去复查（-500~-2,000 元） | 自己调理（下月 -10%） |
| 中奖短信陷阱 | 信了打钱（-3,000 元） | 直接拉黑（+2 次抽卡） |

### 3. 事件队列顺序

抽卡 → 抽卡结果弹窗（录取/放弃）→ 随机事件弹窗（知道了）→ 抉择弹窗（选择）。

多个事件依次展示，刷新页面会自动恢复未处理的事件弹窗。

## 六、操作说明

| 按钮 | 功能 |

| 单抽 | 消耗 1 次抽卡机会，先过月再抽 1 张卡 |

## 九、策略提示

1. **前期**：尽快入职任何工作止损（无业每月净亏房租+生活费），R 卡录取率高可作过渡
2. **中期**：攒抽卡机会冲 SR/SSR，高薪工作配合低支出区（临平、钱塘）积累净资产
3. **黑心公司**：高薪但坏事概率翻倍，若净资产紧张可主动离职规避
4. **过劳**：会叠加影响下月收入，遇到「清除过劳」抉择及时利用
5. **十连抽**：10 张中只选 1 张录取，适合筛选高等级卡牌
6. **作者（SSSR）**：月薪 10 万，入职后约 10 个月即可达成百万目标，但千分之一概率极难遇到
